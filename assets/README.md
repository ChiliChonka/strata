# Strata Visual Assets

Planned structure:

```text
assets/
├── brand/
│   ├── logo-mark.svg
│   ├── wordmark.svg
│   └── logo.svg
├── wallpapers/
│   └── default.*
└── greeter/
    └── background.*
```

## Policy

- Prefer SVG for logos.
- Keep editable source assets.
- Document licenses.
- Do not embed branding directly into functional scripts or binaries.
- Functional code must not depend on visual assets being present.
